# Zepto Data AI Capstone Project

This repository contains the complete implementation of the Zepto Data AI Capstone Project.

## Project Modules

### Module 1 - Data Pipeline
- Web data collection
- Data cleaning and transformation
- SQLite database creation
- SQL-based data analysis

Folder:
`/data_pipeline`

### Module 2 - Analytics
- Exploratory Data Analysis (EDA)
- Missing-value and outlier analysis
- Statistical analysis
- Data visualization
- Machine learning classification
- Class imbalance handling
- Hyperparameter tuning
- Model evaluation
- Saved machine learning pipeline

Folder:
`/analytics`

### Module 3 - Support Assistant
- Zepto policy document corpus
- Sentence Transformer embeddings
- ChromaDB vector database
- Top-k semantic retrieval
- Structured prompt generation
- LangGraph workflow
- Policy and general question routing
- Mock LLM mode
- Pydantic response validation
- FastAPI `/ask` endpoint
- Docker support

Folder:
`/support_assistant`
